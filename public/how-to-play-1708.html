How to Play 1708: Number Puzzle Rules and Strategy Tips

Written by Asim Nawaz · Creator and developer of 1708

1708 is a mathematical number puzzle game built around one clear challenge: reach exactly 1708. You combine number tiles using arithmetic and power operations, but each move uses a limited operation token. You need to plan your moves instead of using operations randomly.

Play the 1708 game

What is the 1708 game?

1708 is a number-and-logic puzzle created by Asim Nawaz. It turns familiar math operations into a resource-management challenge: every move changes the numbers available to you, and the operation tokens you spend are limited. The objective is to create a tile whose value is exactly 1708.

The game offers different modes, including Classic, Founder, Practice, and Daily. Starting numbers and rules can vary by mode, so read the mode's on-screen instructions before you begin.

The five operations

+Addition

Combine two eligible number tiles to create their sum.

−Subtraction

Combine two different eligible tiles to create their absolute difference.

×Multiplication

Multiply two eligible tiles. The game restricts certain inputs, so not every pair can be used.

²Squaring

Use the square operation on one eligible tile: for example, 4 becomes 16.

nⁿSelf-power

Raise an eligible number to itself. For example, 3 becomes 3³ = 27.

These examples explain the math, not a promise that every example is legal in every game state. The game's current input rules determine which moves are available.

How a move works

  1. Select an operation that has a token remaining.
  2. Select the required tile or pair of tiles for that operation.
  3. If the move is legal, the selected input tile or tiles are consumed and the result appears as a new tile.
  4. Keep managing your remaining tiles and tokens until you reach 1708 or no legal move remains.

A move is useful only if it brings you closer to a workable path. A large number is not automatically a good result if it leaves you with no way to reach the target.

Practical strategy tips

  • Check your tokens first. Before making a move, consider which operations you may need later.
  • Think one or two moves ahead. Ask what numbers will remain after a combination and whether those numbers can still be useful.
  • Use powers carefully. Squaring and self-power can create large values quickly, but a large value can also make the target harder to reach.
  • Do not assume the biggest number is best. The goal is exactly 1708, not simply the highest possible tile.
  • Learn from failed attempts. Notice which operation or tile choice removed a useful option, then try a different sequence.
  • Understand the selected mode. Modes may use different starting tiles or special restrictions.

What happens when the game ends?

You win when a tile reaches exactly 1708. A run can end in a loss when the available operation tokens are exhausted or there are no legal moves left before reaching the target. The challenge is to use the available moves efficiently.

Frequently asked questions

Is 1708 free to play?

Yes. The web version is available to play for free at 1708game.vercel.app.

What is the goal of 1708?

The goal is to create a tile with the exact value 1708 using the permitted operations and limited tokens.

Is 1708 just a calculator?

No. The challenge is not only calculating results. You must also choose legal moves, manage a limited set of operation tokens, and preserve useful numbers for later moves.
