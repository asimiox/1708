1708

1708 is a mathematical number puzzle game created and developed by Asim Nawaz.

The goal is to reach exactly 1708 by combining number tiles with addition, subtraction, multiplication, squaring, and self-power operations while managing a limited set of operation tokens.

The game is available to play for free in a web browser. Its source repository is public so players can explore the project and its development.
